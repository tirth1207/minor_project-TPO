# DOCUMENT 9: Use Cases

**Use Case 1: Mentor Approves Student Profile**

| **Field** | **Detail** |
| --- | --- |
| **ID** | UC-01 |
| **Actor** | Mentor |
| **Pre-conditions** | Mentor is logged in. Student profile status is **`PENDING`**. |
| **Main Success Scenario** | 1. Mentor views list of pending students in their department.2. Mentor clicks on a student.3. Mentor clicks the external Resume URL to verify it opens publicly.4. Mentor verifies CGPA and critical details.5. Mentor clicks "Approve".6. System updates status to **`APPROVED`**.7. Student receives notification. |
| **Alternate Flows** | 4a. Resume link returns "Access Denied".&nbsp;&nbsp;&nbsp;&nbsp;1. Mentor clicks "Reject".&nbsp;&nbsp;&nbsp;&nbsp;2. Mentor selects predefined tag: "Resume Link is Private".&nbsp;&nbsp;&nbsp;&nbsp;3. Mentor adds comment: "Please make link public".&nbsp;&nbsp;&nbsp;&nbsp;4. System updates status to **`REJECTED`** and notifies student. |
| **Post-conditions** | Student profile is approved, unlocking the job application functionality for the student. |

**Use Case 2: Student Applies for Job (With AI Gate)**

| **Field** | **Detail** |
| --- | --- |
| **ID** | UC-02 |
| **Actor** | Student |
| **Pre-conditions** | Student is logged in. Student profile is **`APPROVED`**. Job is active. |
| **Main Success Scenario** | 1. Student views job details.2. System runs Eligibility Engine (Branch, CGPA, Backlogs).3. System returns "Eligible".4. System checks Job settings: **`require_mock = false`**.5. System renders "Apply" button.6. Student clicks "Apply".7. System creates Application record.8. Company sees student in applicant list. |
| **Alternate Flows** | 3a. System returns "Ineligible".&nbsp;&nbsp;&nbsp;&nbsp;1. System hides "Apply" button.&nbsp;&nbsp;&nbsp;&nbsp;2. System displays specific reason (e.g., "CGPA 7.0 < Required 8.0").4a. System checks Job settings: **`require_mock = true`**.&nbsp;&nbsp;&nbsp;&nbsp;1. System checks student's AI mock test history for this job role.&nbsp;&nbsp;&nbsp;&nbsp;2a. No passing score found.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;- System hides "Apply", shows "Pass Mock Test to Apply".&nbsp;&nbsp;&nbsp;&nbsp;2b. Passing score found.&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;- System renders "Apply" button, displays AI score to Company. |
| **Post-conditions** | Application record created with status **`APPLIED`**. Applicant blind count increments by 1. |
